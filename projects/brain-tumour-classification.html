Brain Tumour Classification

Engineered a medical imaging model using VGG16 transfer learning to classify brain MRI scans into five categories with ~85–90% accuracy, deployed via Streamlit.

View Live DemoView on GitHub

Problem

Build a deep learning system that can automatically classify brain MRI scans into five categories (Glioma Tumor, Meningioma Tumor, Pituitary Tumor, No Tumor, and an “Unknown” class for external objects or noise) to support medical AI research and education.

Data

Kaggle and a custom dataset: 12,010 images in total, organized into train, validation and test folders. Test sets were balanced to 224 images per class.

Approach

  • Transfer learning with VGG16 (frozen base).
  • Custom head: Flatten → Dense (512, ReLU) → Dropout (0.5) → Dense (5, Softmax).
  • Image size 224×224, batch size 64, 15 epochs, Adam optimizer (lr = 0.0001).
  • Augmentation: rotation, shift, shear, zoom and flip. Dropout used to reduce overfitting.

Stack

Technology
Python
TensorFlow
Keras
VGG16
Streamlit

Results

Training accuracy ~95%, validation accuracy ~85–90%, test accuracy ~85%.

What I’d improve

Add confidence thresholding and explainability (e.g., Grad-CAM) to show which MRI regions drove the prediction, making the tool more trustworthy for educational demonstrations.
